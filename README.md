# Agile Docs & Code Sprint

Atividade que simula uma sprint do Scrum para desenvolver um **conversor de moedas em Python**, com critérios de aceitação, documentação técnica e testes unitários (`unittest`).

- **Quadro do Trello:** <https://trello.com/b/SsCVKm1Z/agile-docs-code-sprint>

## Entregas

| Entrega | Arquivo |
|---------|---------|
| Critérios de aceitação | [`docs/criterios_de_aceitacao.md`](docs/criterios_de_aceitacao.md) |
| Documentação técnica (conversor e login) | [`docs/documentacao_tecnica.md`](docs/documentacao_tecnica.md) |
| Código do conversor | [`conversor.py`](conversor.py) |
| Testes unitários | [`test_conversor.py`](test_conversor.py) |

## Como executar

Precisa apenas do Python 3 instalado (não usa bibliotecas externas).

```bash
python conversor.py
```

## Como rodar os testes

```bash
python -m unittest -v
```
